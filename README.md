# Taxi Data Analysis Using Python

## Project Overview

This project focuses on cleaning, analyzing, and visualizing taxi trip data using Python. The analysis helps understand trip distance, fare, payment methods, pickup boroughs, tips, and other numerical relationships.

## Dataset

* Dataset: Seaborn Taxi Dataset
* Loaded using the Seaborn library
* The dataset contains information about taxi trips, including pickup and drop-off details, distance, fare, tip, tolls, payment method, and total amount.

## Data Cleaning

* Inspected the dataset shape, columns, and data types.
* Identified numerical and categorical columns.
* Checked missing values and calculated their percentages.
* Removed rows with missing values below the defined threshold.
* Checked for duplicate records.
* Checked the datetime columns.
* Sorted the data based on the pickup timestamp for time-based analysis.

## Data Visualization

The following visualizations were created using Matplotlib, Pandas, and Seaborn:

* Line Chart – Fare Over Time
* Bar Chart – Total Fare by Pickup Borough
* Pie Chart – Distribution of Trips by Payment Method
* Histogram – Distribution of Trip Distance
* Box Plot – Tip Distribution by Pickup Borough
* Count Plot – Number of Trips by Pickup Borough
* Scatter Plot – Distance vs Fare
* Heatmap – Correlation Between Numerical Variables
* Pair Plot – Pairwise Relationships
* Violin Plot – Fare Distribution by Payment Method

## Key Analysis Areas

* Taxi fare variation over time
* Total fare by pickup borough
* Distribution of payment methods
* Distribution of trip distances
* Tip distribution across pickup boroughs
* Number of trips by pickup borough
* Relationship between distance and fare
* Correlation between numerical variables
* Pairwise relationships among distance, fare, tip, and total
* Fare distribution across payment methods

## Project Outcome
This project demonstrates the use of Python for data cleaning, exploratory data analysis, and data visualization. The analysis provides a better understanding of taxi trip patterns, fares, distances, payment methods, and relationships between numerical variables.
